# TouchGrass

TouchGrass is a gentle companion for getting outside: choose the kind of place
you're heading to, your available time, energy, and social comfort, then get
three optional quests to help notice, connect, move, or play.

This first prototype has no accounts and no streaks. Quest completions, points,
skills, and badges are saved in local storage on the current browser/device.
Nothing is submitted to MongoDB. Every quest set is generated by a local Ollama
model from the selected outing settings; the app does not substitute fixed
quests if model generation fails.

## Run locally

1. Copy `Server/.env.example` to `Server/.env`, then start MongoDB.
2. Run Ollama and pull a model, for example `ollama pull gemma4:latest`. Set
   `OLLAMA_MODEL` in `Server/.env` to a model installed in your Ollama.
3. In `Server/`, run `npm install` if needed, then `npm run dev`.
4. In `Client/`, run `npm install` and `npm run dev`.
5. Open the Vite URL shown in the terminal (normally `http://localhost:5173`).

The Vite development server proxies `/api` requests to the Express API on port
5001. Quest generation uses Ollama with thinking disabled and a concise output
limit to reduce wait time. If Ollama is unavailable, the app reports an error
instead of showing prewritten quests.

## Checks

- `cd Server && npm test`
- `cd Client && npm run build`
